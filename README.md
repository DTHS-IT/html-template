# HTML Codespaces Starter Template

Use this template to begin your HTML/CSS project in GitHub Codespaces.

## Files and Folders

- `index.html` — Main webpage
- `css/style.css` — Stylesheet
- `images/` — Store website images here

## Getting Started

1. Open the project in GitHub Codespaces.
2. Open `index.html`.
3. Replace the placeholder content with your own content.
4. Add your CSS rules to `css/style.css`.
5. Save images inside the `images` folder.
6. Preview and test your webpage as you work.

## Reminder

Commit and sync your work regularly using the Source Control panel in Codespaces.
